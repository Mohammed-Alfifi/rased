# الحوكمة والخصوصية والأمن

صُمّم النظام ليدعم قرار المسؤول لا ليحل محله، وليسهّل الالتزام بضوابط الهيئة الوطنية للأمن السيبراني ونظام حماية البيانات الشخصية. المطابقة الرسمية تحتاج مراجعة من الأمن السيبراني والشؤون القانونية في الجهة قبل التشغيل.

| المبدأ | كيف طُبّق | أين في الكود |
| --- | --- | --- |
| الإنسان يقرر | كل تنبيه يحتاج تأكيداً أو رفضاً مع السبب، باسم المشغّل ووقته. تغيير قرار سابق يحتاج مشرفاً ويُسجَّل كتغيير | `events.controller.ts` (review) |
| التنبؤ للأماكن لا للأشخاص | التحليل يستخدم أعداداً تجميعية لكل منطقة، ولا يحفظ أي هوية، ولا توجد أي واجهة لتقييم فرد | `analytics/core.py`، و`zone_metrics` |
| بدون هوية | لا تعرّف على الوجوه ولا تحليل للمشاعر. أرقام التتبع مؤقتة وتنتهي بخروج الشخص من الصورة | `vision/detector.py` |
| تمويه الوجوه | كل مقطع ولقطة تُحفظ بوجوه مموّهة تمويهاً لا يُعكس. يمكن تعطيله فقط بمتغير بيئة على الخادم | `vision/clips.py` |
| تشغيل محلي معزول | لا يحتاج إنترنت. قاعدة البيانات والخدمات على شبكة داخلية بدون منفذ خارجي، والخط مضمّن في الواجهة، والنماذج مضمّنة في الصورة | `deploy/docker-compose.yml` |
| صلاحيات حسب الدور | مشغّل، ومشرف، ومدير، ومسؤول نظام. الحساب الموقوف يفقد الوصول فوراً. روابط RTSP (وفيها كلمات مرور) لا تظهر إلا لمسؤول النظام | `auth.guard.ts`، و`cameras.controller.ts` |
| سجل تدقيق كامل | الدخول ومحاولاته الفاشلة، وعرض أي تنبيه، ومشاهدة أي مقطع وتصديره، وكل قرار، وكل تغيير في الإعدادات والمستخدمين والكاميرات، والحذف التلقائي | `audit_log` |
| لا يمكن العبث بالسجل | trigger في قاعدة البيانات يرفض أي تعديل أو حذف في `audit_log`، حتى من التطبيق نفسه | `001_init.sql` |
| مقاطع بروابط مؤقتة | المقطع لا يُفتح إلا برابط مدته 5 دقائق يُصدَر لمستخدم مسجّل، ويُسجَّل إصداره. التصدير للمشرف فأعلى | `media-token` |
| مدة احتفاظ محددة | تحددها الجهة من الإعدادات (افتراضياً 30 يوماً)، ويُحذف ما يتجاوزها كل ساعة مع تسجيل الحذف. سجل التدقيق لا يُحذف | `retention.service.ts` |
| وضع الظل | التشغيل يبدأ به افتراضياً: تُسجَّل التنبيهات للقياس ولا تصل للمشغّلين، حتى يقرر المسؤول إيقافه | `settings.shadow_mode` |
| إيقاف فوري | أي كاميرا تُوقف من الإعدادات، وتتوقف معالجتها خلال دقيقة | `cameras.enabled` |
| الأسرار | مفاتيح الجلسات والخدمة وكلمة مرور قاعدة البيانات من متغيرات البيئة، والإنتاج يرفض التشغيل بدونها. كلمات المرور مشفرة بـbcrypt | `config.ts` |

## قبل التشغيل في أي منشأة

- [ ] موافقة مكتوبة على استخدام بث الكاميرات وتحديد منطقة التجربة.
- [ ] مراجعة الأمن السيبراني: عزل الخادم، وربطه بشبكة الكاميرات للقراءة فقط، وTLS أمام الواجهة.
- [ ] اعتماد مدة الاحتفاظ والصلاحيات وأسماء المستخدمين.
- [ ] تغيير كلمة مرور admin بعد أول دخول، وحذف `RASED_ADMIN_PASSWORD` من ملف البيئة.
- [ ] نسخ احتياطي لقاعدة البيانات (مثل `pg_dump` يومياً إلى وسيط داخلي).
